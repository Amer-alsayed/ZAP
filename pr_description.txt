💡 What: Added a spinning loader icon (`RefreshCw` from lucide-react) to the authentication button when a login or registration request is in progress.
🎯 Why: Cryptographic operations on the client-side (such as key derivation) take some time, and clicking the button without immediate visual feedback can cause the user to doubt whether the app is responding or not. By adding an animated spinner, the UI provides immediate response to the click action, making the app feel significantly faster and more interactive while blocking further submissions.
📸 Before/After: Before, the button merely disabled itself and changed text to "Processing Cryptography...". After, it changes to an animated spinner accompanied by "Processing Cryptography..." in a nicely centered flex layout.
♿ Accessibility: The button was already properly labeled and disabled. The text is still readable, and the animated spinner adds an additional visual cue for users with cognitive or visual impairments relying on clear state transitions.
